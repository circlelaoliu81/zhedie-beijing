# 折叠北京

`feature/zhedie-beijing` 分支：FoloToy AI Passport 上的离线掌上人生模拟「折叠北京」。
不沿用基线 demo 测试菜单，使用独立 UI、纯本地确定性数据表与三键交互。

## 设备与边界

- ESP32-C3 / 8 MB Flash / 无 PSRAM / 240×320 ST7789P3 / UP·DOWN·OK 三键。
- 纯离线：不联网、不配网、不采集个人信息、不调用云端模型。
- 一局 100 天，一天 24 小时，干活与睡觉由玩家自己分配。
- 进度自动存 NVS（进入新一天 / 收工结算时落盘），随时关机不丢；封面提供「继续上次」。

## 玩法

- 五条活路：夜市摆摊（选点位 × 选品类）、送外卖（先有电动车）、日结零工（无门槛，工钱当天结）、
  网约车（先付押金租车，深夜档流水高）、直播（连续开播涨粉，粉丝到量才接商单）。
- 健康 / 精力随工时下降；连续熬夜会犯困，收入打八折、六折，扛不住当场晕倒，医药费与当天工夫一起没了。
- 每天一条新闻、一次随机事件、一句旁白；借钱有日息，存款也有日息。
- 仓储有上限，可花钱扩容。

## 按键与息屏

- UP / DOWN：上下移动光标。
- OK 单击：确定 / 出工 / 买入。
- OK 长按：返回上一层（封面与结局页不响应）。
- 60 秒无按键操作自动关闭背光省电；此时按任意键只负责点亮屏幕，再按一次才执行动作。
  熄屏只关背光不清屏，唤醒不需重绘、不会闪黑。

## 构建与门禁

激活移动硬盘上的 ESP-IDF 5.5.3 环境后，在仓库根目录运行：

```bash
source "/Volumes/Extreme SSD/_toolchain/env-xuanmen.sh"
bash tools/validate.sh             # 美术 / 字符集 / 引擎 / 页面 / 存档 / 息屏
bash tools/validate.sh --build     # 再加固件构建
```

门禁对应的是「编译通过但设备上是坏的」这类故障：美术二进制长度错（花屏）、字库缺字（空白方块）、
页面文本越界或重叠、存档往返不一致或坏档被读回、熄屏后第一下按键被漏派发。

### 构建标识（build id）的发布口径

`tools/xm/gen_build_id.py` 取当前 git 短哈希，脏工作区追加 `-dirty`。脏判定用
`git status --porcelain`（覆盖未跟踪文件），不能改用 `git diff --quiet`。

**发布包以「功能提交」的哈希为 build id，纯元数据提交（刷新 build id、文档）不刷 build id。**
原因是 build id 写入文件、提交该文件又会推进 HEAD，形成自指循环。

## 素材与预览

- 插画源图：`assets/art_src/*.png`，由 `tools/xm/make_fb_art.py` 裁切、提亮、4×4 Bayer 抖动后
  转 RGB565 嵌入固件；缺图时回退到程序化场景。
- 主机预览：`python3 tools/xm/fb_preview.py` 输出 `preview/`（不点亮真机也能看每一页的排版）。

## 本次不实现

语音 / TTS、BLE、横屏、OTA、云端解读、历史导出、成就系统。只作记录，不提供假入口。

未经用户明确同意，不执行任何烧录、USB/串口写入或设备数据清除操作。主机预览图与固件编译通过
均不等于真机中文显示验收。
